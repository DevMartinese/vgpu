Geistdocs 实现了 [llms.txt 标准](https://llmstxt.org/) —— 一种约定，将您所有的文档内容提供为单个、AI 可读的文本文件。这使得语言模型可以一次性轻松理解您的完整文档。

## 它是什么

`/llms.txt` 端点以单次响应返回您所有的文档页面，格式为纯 Markdown。每个页面之间用空行分隔，便于 AI 工具解析和理解您的完整文档。

### 访问

```
https://yourdomain.com/llms.txt
```

将所有文档页面串联为纯文本返回。

## 工作原理

该端点会：

1. 从您的文档中获取所有页面
2. 处理每个页面以提取干净的 Markdown
3. 将所有内容合并为单个文本文件
4. 以 `text/markdown` 返回

页面之间使用双换行符 (`\n\n`) 连接以便清晰分隔。

## 配置 sources

生成的项目使用一个文档 source：

```ts title="app/[lang]/llms.txt/route.ts"
import { createLlmsRoute } from "@vercel/geistdocs/routes/llms";
import { geistdocsSource } from "@/lib/geistdocs/source";

export const { GET, revalidate } = createLlmsRoute({
  source: geistdocsSource,
});
```

有多个内容区或版本的站点可以传入 `sources`：

```ts title="app/[lang]/llms.txt/route.ts"
export const { GET, revalidate } = createLlmsRoute({
  sources: [docsSource, cookbookSource],
});
```

## 使用场景

此功能可用于：

- **AI 训练** - 将您的文档作为 AI 助手的上下文
- **搜索索引** - 将您完整的文档提供给搜索系统
- **内容分析** - 分析跨文档的模式和内容
- **批量处理** - 一次处理所有文档
- **LLM 上下文** - 为语言模型提供完整的文档上下文

## llms.txt 标准

llms.txt 标准是一种简单的约定，使文档对 AI 工具更易访问。它在精神上类似于 `robots.txt`，但设计目标是面向语言模型而非搜索爬虫。

在 [llmstxt.org](https://llmstxt.org/) 了解更多。
